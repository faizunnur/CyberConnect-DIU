# Security checklist (status at M8, 30 Oct 2026)

| Area | Control | Status |
|---|---|---|
| Authentication | Argon2id (19 MiB, t=2, p=1), uniform responses on register/forgot-password, Redis rate limits, nginx limits on auth endpoints | Done, tested (`AuthenticationFlowIT`) |
| Sessions | Redis-backed, HttpOnly/SameSite=Lax/Secure cookie, fixation protection, revocation on reject/suspend/deactivate/password/privilege change | Done, tested |
| MFA | TOTP (RFC 6238, replay-protected) + hashed single-use recovery codes, mandatory for privileged roles, step-up for document view/roles/suspension/appeals | Done, tested |
| CSRF | Cookie + header double submit on every non-GET and on WebSocket CONNECT | Done, tested (`WebSocketIT`) |
| Authorization | Server-side account-status filter + fine-grained authorities, ownership/membership checks on every endpoint, uniform 404s | Done, tested (`AuthorizationMatrixIT` + module ITs) |
| Input | Bean Validation, plain-text sanitisation, size limits, magic-byte upload checks, image re-encode, PDF active-content rejection | Done, tested |
| Post attachments | content sniffing (declared type ignored), photo re-encode without metadata, OOXML without macros, malware scan, visibility-checked streaming with `nosniff`, `sandbox` CSP and download disposition for documents (`PostAttachmentIT`) | Done, tested |
| Documents | AES-256-GCM, private bucket, backend streaming only, per-view audit, retention purge, real collection behind a feature flag | Done, tested |
| Malware | ClamAV mandatory in production (fail closed), opt-in `ClamAvEicarIT` | Done |
| Transport | TLS 1.2/1.3 at nginx, HSTS, HTTP→HTTPS redirect | Config ready (`prod.conf`) |
| Headers | nosniff, DENY framing, referrer policy, permissions policy, CSP (script/style `unsafe-inline` because of Next.js inline bootstrap) | Done; **follow-up:** nonce-based CSP via Next middleware |
| Secrets | `.env` only, generated by `scripts/gen-secrets`, never committed (`.gitignore`), guards refuse dev settings in prod | Done |
| Logging | No secrets/PII/document bytes; ECS JSON; request ids | Done |
| Dependencies | OWASP Dependency-Check, Trivy, Semgrep workflows (manual until 1 Nov 2026) | Configured; **run before go-live** |
| Realtime | Origin check, verified-only handshake, read-only user queues | Done, tested |
| Privacy | Per-field profile visibility, blocks, message requests, moderators never browse conversations | Done, tested |
| Backups | Scripted dump + volume archives; restore drill procedure | Scripted; **first drill pending** |

## Before go-live
1. Institutional approval for identity-document collection recorded → set `verification.real_documents_enabled`.
2. Run the Security workflow (Semgrep, Dependency-Check, Trivy) and fix findings rated high or critical.
3. Penetration test of the deployed instance (external party) focusing on verification, documents and messaging.
4. Restore drill (backup-restore.md) completed once.
5. Privacy notice and terms reviewed by the institution (frontend `/privacy`, `/terms`).
